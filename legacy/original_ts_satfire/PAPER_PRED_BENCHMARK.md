# TS-SatFire Prediction Benchmark

This benchmark separates model architecture from the proposed input and prior features.

## Fixed protocol

- Models: `unet3d`, `attunet`, `unetr3d`, `swinunetr3d`
- Target: next-day new-fire mask generated by the existing prediction pipeline
- Test metric: the original per-window, then per-fire macro F1 and IoU
- Paper profile:
  - U-Net-3D: DiceCE, learning rate `0.001`, batch `64`
  - Attention-U-Net-3D: Dice, learning rate `0.0012`, batch `8`
  - UNETR-3D: DiceCE, learning rate `0.001`, batch `4`
  - SwinUNETR-3D: DiceCE, learning rate `0.001`, batch `8`, feature size `36`
  - DiceCE foreground weight: `446.7836`
  - Dice:CE mixture: `1:1`

The paper does not report the number of epochs. The launcher defaults to 200 because the public test code refers to epoch 199, but validation loss selects the checkpoint. Report this as a reproduction choice rather than a paper-provided setting.

## Baseline

Run one seed before expanding the experiment:

```bash
conda activate ts-satfire
cd /home/jlc3q/New_project/TS-Agentic-AI

export TS_SATFIRE_ORIG_DATASET_ROOT=/local/scratch/$USER/ts-satfire-pred-spatial-ts6
export TS_SATFIRE_PAPER_CHECKPOINT_ROOT=/local/scratch/$USER/checkpoints/ts_satfire_paper_pred

TS=6 \
SEEDS=42 \
EPOCHS=200 \
MODELS="unet3d attunet unetr3d swinunetr3d" \
GOES_VARIANT=none \
EXPERIMENT_TAG=viirs43 \
bash legacy/scripts/run_pred_paper_benchmarks.sh
```

If U-Net-3D batch 64 does not fit, set `UNET3D_BATCH=8`. This is no longer an exact paper batch and must be reported. Gradient accumulation does not reproduce BatchNorm batch statistics.

## Model-Independent GOES Input

The same six aligned GOES maps can be concatenated to every architecture:

```bash
TS=6 \
SEEDS=42 \
EPOCHS=200 \
MODELS="unet3d attunet unetr3d swinunetr3d" \
GOES_VARIANT=goes_spatial_frontbuf \
EXPERIMENT_TAG=goes_frontbuf_concat \
bash legacy/scripts/run_pred_paper_benchmarks.sh
```

This changes only the input stem from 43 to 49 channels. The architecture family, loss, split, checkpoint selection, and test metric remain fixed. Shared augmentation applies the same flip and rotation to VIIRS, labels, and GOES.

## Three Seeds

After selecting the viable architectures and feature variants:

```bash
TS=6 \
SEEDS="42 43 44" \
MODELS="unet3d swinunetr3d" \
GOES_VARIANT=none \
EXPERIMENT_TAG=viirs43 \
bash legacy/scripts/run_pred_paper_benchmarks.sh
```

Run the selected proposed variant with the same models and seeds. Then summarize all results:

```bash
python legacy/scripts/summarize_pred_paper_benchmarks.py \
  --checkpoint-root /local/scratch/$USER/checkpoints/ts_satfire_paper_pred \
  --baseline-tag viirs43
```

The summary reports absolute F1 and IoU changes against the matching baseline model, TS length, interval, and seed.

## Candidate Prior

The tabular candidate model is not an input channel and should not be presented as a new deep architecture. Its probability must be joined to each dense model's probability map using the same validation-tuned post-prior rule. That produces a second controlled comparison:

1. Dense model only
2. Dense model plus GOES input
3. Dense model plus candidate post-prior
4. Dense model plus GOES input and candidate post-prior

Candidate-only local-growth IoU is not directly comparable with the full TS-SatFire prediction metric.
